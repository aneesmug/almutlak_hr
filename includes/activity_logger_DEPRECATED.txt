# DEPRECATED: includes/activity_logger.php

This file is **DEPRECATED** as of [current date] and should NOT be used.

## Why It's Deprecated

The original `activity_logger.php` was based on an older database schema with the following columns:
- `user_editor` (instead of `user_id`)
- `pg_id` (instead of `record_id`)
- `old_value` (instead of `old_values` with JSON)
- `new_value` (instead of `new_values` with JSON)

## Migration to New System

The new enhanced `ActivityLogger` class is now in `includes/init.php` and supports your complete 16-column schema:
- user_id, user_name, module, page, record_id, table_name
- old_values (JSON), new_values (JSON) with full change tracking
- severity levels (INFO, WARNING, CRITICAL, ERROR)
- status tracking (SUCCESS, FAILED, PENDING)
- Complete metadata (ip_address, user_agent, created_at)

## What to Do

1. **DO NOT** use or import `includes/activity_logger.php`
2. **DO** use `ActivityLogger` class from `includes/init.php` (auto-loaded on all pages)
3. Reference the following documentation:
   - `ACTIVITY_LOGGING_GUIDE.md` - Complete method reference
   - `ACTIVITY_LOGGING_IMPLEMENTATION_GUIDE.md` - Implementation patterns
   - `ACTIVITY_LOGGING_TEMPLATES.php` - Copy-paste code examples
   - `LOGGING_ROLLOUT_CHECKLIST.md` - Systematic integration guide
