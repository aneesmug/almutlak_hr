# Quick Checklist: Why Settlement Emails Are Not Being Sent

## 🔍 Diagnostic Tool (USE THIS FIRST)

After creating an EOS settlement, access this URL in your browser:

```
http://your-site.com/debug_settlement_email.php?settlement_inv_no=SETL-YOUR-REQUEST-NUMBER
```

**Example:**
```
http://localhost/almutlak/system/debug_settlement_email.php?settlement_inv_no=SETL-RES-2024-001
```

This tool will automatically check all 7 critical components and show you exactly what's missing!

---

## ⚡ Quick Fixes (Top 5 Most Common Issues)

### Issue #1: Approver Has No Email
**Symptom:** "Approver email is empty" in debug tool
**Fix:** Add email to admin_login table
```sql
UPDATE admin_login SET email = 'approver.email@domain.com' WHERE emp_id = 'approver_id';
```

### Issue #2: SMTP Settings Not Configured
**Symptom:** "MISSING" status for smtp_host, smtp_port, etc.
**Fix:** Add SMTP settings to app_settings table
```sql
INSERT INTO app_settings (setting_key, setting_value) VALUES 
('smtp_host', 'smtp.gmail.com'),
('smtp_port', '587'),
('smtp_user', 'your-email@gmail.com'),
('smtp_pass', 'your-app-password'),
('smtp_encryption', 'TLS'),
('from_email', 'noreply@almutlak.com'),
('from_name', 'Al Mutlak HR');
```

### Issue #3: Approval Chain Not Configured
**Symptom:** "approval_chain_settlement is NOT configured"
**Fix:** Add approval chain to app_settings
```sql
INSERT INTO app_settings (setting_key, setting_value) VALUES 
('approval_chain_settlement', '{
  "chain": [
    {"position": 1, "approver_type": "dept_manager", "description": "Department Manager"},
    {"position": 2, "approver_type": "finance_manager", "description": "Finance Manager"}
  ]
}');
```

### Issue #4: Settlement Type Not Registered
**Symptom:** "Settlement type NOT found in approval_request_types"
**Fix:** Register settlement request type
```sql
INSERT INTO approval_request_types (type_name, description) 
VALUES ('settlement', 'Settlement Records');
```

### Issue #5: No Approvers in Chain
**Symptom:** "No approvers found in request_approvers table"
**Fix:** This usually means the approval_chain_settlement setting wasn't configured (see Issue #3)

## 📧 Email Sending Flow

When EOS is submitted:
1. Settlement record created in `settlement_records` table
2. Approval chain created in `request_approvers` table via ApprovalChainManager
3. First pending approver identified
4. Email sent to approver via PHPMailer (if all conditions met)

**Email sending requires:**
- ✓ Approver found in approval chain
- ✓ Approver has email in admin_login
- ✓ SMTP settings configured
- ✓ PHPMailer library loaded
- ✓ No PHP errors in email template

## 📍 Key Database Tables

| Table | Purpose | What to Check |
|-------|---------|---------------|
| settlement_records | Settlement records | Should have SETL- prefixed records |
| request_approvers | Approval chain | Should have entries for settlement |
| app_settings | System config | SMTP & approval_chain_settlement |
| approval_request_types | Request types | Must have 'settlement' type |
| admin_login | User accounts | Approver must have email |
| employees | Employee data | Employee dept for routing |

## 💡 Pro Tips

1. **Test SMTP first:** Use Mailtester or telnet to verify SMTP works
2. **Check spam folder:** New SMTP settings often get marked as spam initially
3. **Verify approver dept:** Approver must be dept_manager or finance_manager of employee
4. **Check logs regularly:** Errors are logged with clear messages
5. **Use debug tool:** It shows exactly what's wrong in 30 seconds
