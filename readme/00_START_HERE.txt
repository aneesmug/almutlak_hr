🎓 HOW TO CAPTURE SCREENSHOTS:

SETUP:
  1. Login as employee
  2. Navigate to feature (Profile → More → Apply Vacation)
  3. Fill in example data

CAPTURE:
  Windows:  Press PrintScreen or Win+Shift+S
  Mac:      Press Cmd+Shift+4
  Linux:    Use system screenshot tool

SAVE:
  1. Save as PNG (best quality)
  2. Optionally crop/annotate
  3. Keep around 1024x768px

UPLOAD:
  1. Go to manage_guide_screenshots.php
  2. Select section and step
  3. Add descriptive title
  4. Upload image
  5. Done!

💾 DATABASE TABLE CREATED:

Table: guide_screenshots

Columns:
  id              - Auto-increment ID
  section         - Section name (vacations, loans, excuse, etc.)
  step_number     - Step number (1, 2, 3)
  title           - Display title for screenshot
  filename        - Original uploaded filename
  file_path       - Relative path to image
  display_order   - Order in gallery
  is_active       - Show/hide toggle
  uploaded_by     - Admin user ID who uploaded
  created_at      - Upload timestamp
  updated_at      - Last modified timestamp

Indexes:
  - idx_section (for quick section queries)
  - idx_step (for quick step queries)
  - idx_active (for active screenshots only)
