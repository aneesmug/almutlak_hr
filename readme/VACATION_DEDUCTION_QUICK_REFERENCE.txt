# Vacation Deduction Calculation - Quick Reference

## What Changed?

**OLD Formula:**
```
Deductible Days = Vacation Days - Holiday Days
❌ Weekend days were NOT excluded - employees lost vacation for weekends!
```

**NEW Formula:**
```
Deductible Days = Vacation Days - Weekend Days - Holiday Days
✓ Both weekends AND holidays are excluded from deduction
✓ Employees only lose vacation for actual working days
```

## Key Examples

### Example 1: Vacation During Weekend
```
Vacation: Friday + Saturday (2 days)
Weekends: Friday + Saturday (2 days)
Holidays: None (0 days)

CALCULATION: 2 - 2 - 0 = 0 days deducted ✓
Meaning: No vacation balance used!
```

### Example 2: Vacation During Holiday
```
Vacation: Thursday - Monday (5 days)
Weekends: Friday + Saturday (2 days)
Eid Holiday: Friday - Sunday (3 days, assigned to your company)

CALCULATION: 5 - 2 - 1 = 2 days deducted
(Note: Fri-Sat already counted as weekend, only Sun additional)
```

### Example 3: Vacation Fully Covered
```
Vacation: Thursday - Monday (5 days)
Weekends: Friday + Saturday (2 days)
3-Day Eid: Thursday - Saturday (3 days)

CALCULATION: 5 - 2 - 3 = 0 days deducted ✓
Meaning: All vacation days covered by weekend + holiday!
```

## Who Gets What?

### Company A Employee
- Vacation: 5 days during Eid
- Eid assigned to Company A: YES
- **Deduction: 2 days** (5 - weekend - holiday)

### Company B Employee  
- Same vacation dates (5 days)
- Eid assigned to Company B: NO
- **Deduction: 5 days** (5 - weekend only)

**→ Different deductions based on company assignment!**

## Weekend Rules

- **Automatic Detection:** No setup needed
- **Always Excluded:** Friday (5) + Saturday (6)
- **No Configuration:** Hardcoded for Saudi Arabia

## Holiday Rules

1. **Must Be Setup:** Create holidays in Holiday Management
2. **Company-Specific:** Assign to relevant companies only
3. **Automatic Filtering:** Employee's company automatically used

## Common Questions

**Q: Why is my deduction only 2 days instead of 5?**
- A: Because 2 days are weekends + 1 day is a holiday (5 - 2 - 1 = 2)

**Q: My company's holiday isn't being deducted**
- A: Check if holiday is assigned to your company in Holiday Management

**Q: What if vacation spans multiple holidays?**
- A: All applicable holidays are summed and deducted

**Q: Can I see the calculation breakdown?**
- A: Check vacation_calculator.php error logs - each calculation is logged
