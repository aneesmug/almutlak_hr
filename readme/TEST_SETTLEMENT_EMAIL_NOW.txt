## 🚨 If Settlement NOT Created

The `analyze_settlement_logs.php` will show ERROR messages. Common ones:

| Error | Fix |
|-------|-----|
| `Settlement type NOT found` | Run `INSERT INTO approval_request_types (type_name, description) VALUES ('settlement', 'Settlement Records');` |
| `Approval chain missing` | Add `approval_chain_settlement` to app_settings table |
| `No approver found` | Employee's dept_manager doesn't exist in system |
| `SMTP settings missing` | Fill in smtp_host, smtp_port, smtp_user, smtp_pass in app_settings |

---

## 🚨 If Email NOT Sent

The logs will show SUCCESS for settlement creation but FAILURE for email. Check:

| Check | Location |
|-------|----------|
| SMTP configured? | `/system/validate_settlement_config.php` → Phase 7 |
| Approver has email? | `/system/validate_settlement_config.php` → Phase 5 |
| Email in logs? | `/system/analyze_settlement_logs.php` → search for "SEND_EMAIL" |
