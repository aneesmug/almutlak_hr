## Flow Chart: How Deduction is Calculated

```
┌─ START: Employee Takes Vacation ─┐
│                                   │
├─ Get Vacation Details ────────────┤
│  • Start Date: Feb 26             │
│  • End Date: Mar 2                │
│  • Total Days: 5                  │
│  • Employee Company: Company A    │
│                                   │
├─ Count Weekend Days ──────────────┤
│  For each day in date range:      │
│  • Is it Friday? → +1             │
│  • Is it Saturday? → +1           │
│  Result: 2 weekend days           │
│                                   │
├─ Count Holiday Days ──────────────┤
│  Get Company A holidays that:     │
│  • Are active (not archived)      │
│  • Overlap with Feb 26 - Mar 2    │
│  For each overlapping holiday:    │
│  • Count days of overlap          │
│  Result: 3 holiday days           │
│  (but 2 overlap with weekends)    │
│  = 1 additional holiday day       │
│                                   │
├─ Calculate Deduction ─────────────┤
│  Deductible Days =                │
│    Total Days (5)                 │
│    - Weekend Days (2)             │
│    - Holiday Days (1)             │
│    = 2 days                       │
│                                   │
├─ Update Vacation Balance ─────────┤
│  Balance Before: 30 days          │
│  Deductible: 2 days               │
│  Balance After: 28 days           │
│                                   │
└─ END: Deduction Complete ─────────┘
```

## Algorithm Flow (Pseudocode)

```
FUNCTION CalculateVacationDeduction(emp_id, vac_start, vac_end, vac_days):
  
  // Step 1: Get employee's company
  company_id = GetEmployeeCompany(emp_id)
  
  // Step 2: Count weekend days
  weekend_count = 0
  FOR each day IN [vac_start, vac_end]:
    IF IsFriday(day) OR IsSaturday(day):
      weekend_count += 1
  
  // Step 3: Get holidays for this company
  company_holidays = GetHolidaysForCompany(company_id, vac_start, vac_end)
  
  // Step 4: Count overlapping holiday days
  holiday_count = 0
  FOR each holiday IN company_holidays:
    overlap_days = CalculateOverlap(
      vac_start, vac_end,
      holiday.start_date, holiday.end_date
    )
    holiday_count += overlap_days
  
  // Step 5: Calculate deductible days
  deductible = MAX(0, vac_days - weekend_count - holiday_count)
  
  RETURN deductible
END
```
