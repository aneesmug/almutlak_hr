This guide will help you capture and upload screenshots for the system guide. Each section has multiple steps, and we need visual evidence for each step.

## ANNUAL LEAVE - 7 Screenshots

### Step 1: Profile Page Navigation
- **Title**: "Go to Profile Page"
- **Instructions**: 
  1. Log in to the system
  2. Look for your profile link in the header (usually shows your name)
  3. Take a screenshot showing the profile menu/navigation

### Step 2: Click More Button
- **Title**: "Click on More Button"
- **Instructions**:
  1. On your profile page, look for a "More" button or menu
  2. Show where this button is located in the header
  3. Capture it clearly

### Step 3: Select Annual Vacation
- **Title**: "Select Apply Annual Vacation"
- **Instructions**:
  1. Click the More button
  2. Look for "Apply Annual Vacation" option
  3. Capture this dropdown/menu showing the option

### Step 4: Fill Vacation Form
- **Title**: "Fill Vacation Details Form"
- **Instructions**:
  1. Click on "Apply Annual Vacation"
  2. The form will appear
  3. Take a screenshot of the complete form

### Step 5: Choose Dates
- **Title**: "Select Vacation Dates"
- **Instructions**:
  1. In the vacation form, locate the date picker
  2. Click on start date field
  3. Capture the date calendar

### Step 6: Select Vacation Type
- **Title**: "Choose Vacation Type"
- **Instructions**:
  1. In the form, find the "Vacation Type" dropdown
  2. Click to show Annual/Emergency/Fly options
  3. Capture this dropdown

### Step 7: Submit Request
- **Title**: "Click Submit Button"
- **Instructions**:
  1. Fill the form with sample data
  2. Scroll to the bottom
  3. Capture the Submit button clearly

## How to Upload Screenshots

1. Go to: `manage_guide_screenshots.php` (Admin Panel)
2. Select the **Section** (e.g., "vacations", "loans", "excuse")
3. Select the **Step Number** (1-7, depending on section)
4. Enter a **Title** (descriptive name, e.g., "Go to Profile Page")
5. Upload the **Screenshot Image** (JPG, PNG, or GIF)
6. Click **Upload**
7. Repeat for each step

---

## Best Practices for Screenshots

✅ **DO:**
- Use clear, high-quality images
- Ensure text is readable
- Show only relevant parts of the screen
- Highlight important buttons/fields with arrows or boxes if possible
- Use consistent dimensions (recommended: 1280x720 or similar)
- Hide sensitive information (names, IDs, etc.)
- Name files descriptively

❌ **DON'T:**
- Use blurry or low-quality images
- Include sensitive data (passwords, personal info)
- Take screenshots with full screen clutter
- Use very large file sizes (keep under 2MB each)
- Forget to add clear titles

---

## File Size Limit: 5MB per image

If your images are too large:
1. Resize to 1280x720 or 1366x768
2. Compress using an online tool or Photoshop
3. Save as JPEG for better compression

---

## Need Help?

If you encounter issues:
1. Check file format (JPG, PNG, GIF, WebP)
2. Verify image is under 5MB
3. Ensure all fields are filled
4. Contact your system administrator
