## 💡 Pro Tips

### When Taking Screenshots:
- Use same browser every time (for consistency)
- Use consistent screen resolution
- Hide taskbar and notifications
- Highlight important buttons/fields
- Include enough context
- Use good lighting
- Capture clean, professional images

### When Uploading:
- Upload in step order (Step 1, 2, 3...)
- Use clear, descriptive titles
- Add all sections before testing
- Verify images in system guide after
- Compress large files first

### Best Practices:
- Plan all screenshots before taking them
- Use screenshot tool with annotation
- Save originals on your computer first
- Upload duplicates to verify both work
- Test on different browsers/devices

## 🆘 Troubleshooting

### Image Won't Upload?
- Check file format (JPG, PNG, GIF, WebP only)
- Verify file size is under 5MB
- Ensure filename has no special characters
- Try uploading a test image

### Image Not Showing in Guide?
- Verify file was uploaded successfully
- Check browser cache (Ctrl+F5)
- Ensure file path in database is correct
- Try a different image format

### Can't Access Upload Panel?
- Verify you're logged in as admin
- Check user_type is "administrator"
- Clear browser cookies and login again

### File Too Large?
- Compress using TinyPNG or similar
- Reduce resolution to 1280x720
- Convert PNG to JPEG for smaller size
- Check file size before uploading
