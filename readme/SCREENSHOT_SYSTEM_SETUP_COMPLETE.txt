## 🚀 How It Works

### Upload Flow:
```
Admin selects image
     ↓
System validates (format, size)
     ↓
File saved to: assets/screenshots/{section}/{filename}
     ↓
Database entry created (section, step, title, path)
     ↓
Screenshot appears in system_guide.php automatically
```

### Display Flow:
```
Employee views system_guide.php
     ↓
System fetches screenshots by section/step
     ↓
All uploaded images displayed in grid
     ↓
Falls back to icon if no images uploaded yet
     ↓
Image handles errors gracefully (broken image)
```

## 💡 Best Practices

### ✅ DO:
- Use consistent browser and screen size
- Highlight important buttons/fields
- Hide sensitive information
- Keep images 1280x720 resolution
- Use clear, professional titles
- Compress large files
- Upload in step order (Step 1, 2, 3...)
- Take screenshots in good lighting
- Test images before uploading

### ❌ DON'T:
- Use blurry images
- Include passwords/personal data
- Mix different resolutions
- Upload huge file sizes
- Forget titles/descriptions
- Include desktop clutter
- Use very old browser UI
- Forget to save locally first

## 📞 Support & Troubleshooting

### Image Not Showing?
1. Check file format (JPG, PNG, GIF, WebP only)
2. Verify file size is under 5MB
3. Ensure `assets/screenshots/` folder has write permissions
4. Check file path in database

### Upload Fails?
1. Check file format
2. Reduce file size if over 2MB
3. Ensure folder permissions are correct
4. Check browser error console

### Wrong Section?
1. Review database records
2. Check which section/step was selected
3. Re-upload to correct section/step

## 📊 Database Schema

```sql
guide_screenshots table:
- id (Primary Key)
- section (vacations, loans, excuse, resignation, rejoin)
- step_number (1-7)
- title (screenshot description)
- filename (original filename)
- file_path (relative path to file)
- display_order (order within step)
- is_active (1=show, 0=hide)
- uploaded_by (admin user ID)
- created_at (timestamp)
- updated_at (timestamp)

Indexes:
- section + step_number (for quick retrieval)
```
