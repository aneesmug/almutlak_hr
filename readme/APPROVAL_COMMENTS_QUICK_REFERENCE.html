🚀 Getting Started in 3 Steps

Step 1: Include Files in Your Page

<?php require_once __DIR__ . '/includes/approval_comment_form.php'; require_once __DIR__ . '/includes/approval_comment_helpers.php'; ?>

Step 2: Create Approval Function

<script> function approveRequest(requestId, requestType) { openApprovalCommentForm(requestId, requestType, 'approved', function(data) { $.ajax({ url: './includes/ajaxFile/saveApprovalComment.php', type: 'POST', data: data, dataType: 'JSON', success: function(response) { if (response.success) { // Save successful, now proceed with approval performActualApproval(requestId); } } }); }); } </script>

Step 3: Add Buttons to Your Page

<button class="btn btn-success" onclick="approveRequest('REQ-2025-001', 'vacation')"> <i class="fa fa-check"></i> Approve </button> <button class="btn btn-danger" onclick="rejectRequest('REQ-2025-001', 'vacation')"> <i class="fa fa-times"></i> Reject </button>

💾 Database Table Schema

Column Name Type Description
id int(11) Unique comment ID
request_inv_no varchar(255) Request invoice number (e.g., VAC-2025-001)
request_type enum vacation | loan | smart_request | resignation | rejoin
approval_action enum approved | rejected | hold | adjusted
approver_emp_id int(11) Employee ID of approver
approver_name varchar(255) Name of approver (for display)
approval_level int(11) Level in approval chain (1, 2, 3...)
comment_text longtext The actual comment/review (max 5000 chars)
comment_date datetime When comment was added (auto)

🗄️ Common Queries

Fetch All Comments for a Request

SELECT * FROM approval_comments WHERE request_inv_no = 'VAC-2025-001' AND request_type = 'vacation' ORDER BY comment_date ASC;

Get Latest Comment

SELECT * FROM approval_comments WHERE request_inv_no = 'VAC-2025-001' ORDER BY comment_date DESC LIMIT 1;

Count Comments by Action

SELECT approval_action, COUNT(*) as count FROM approval_comments WHERE request_inv_no = 'VAC-2025-001' GROUP BY approval_action;

🆘 Troubleshooting

Form not appearing?

Make sure you included the form file:

<?php require_once 'includes/approval_comment_form.php'; ?>

Comments not saving?

Check these:

  • approval_comments table exists: DESCRIBE approval_comments;
  • saveApprovalComment.php is accessible
  • User session has empid or id set
  • Check browser console for AJAX errors (F12 → Console tab)

Want to customize?

Edit CSS in approval_comment_form.php or modify the JavaScript functions to suit your needs.
