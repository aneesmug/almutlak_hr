📷 TAKING SCREENSHOTS:

1. Login to system as EMPLOYEE
2. Navigate to page (e.g., Profile → More → Apply Vacation)
3. Take screenshot:
   • Windows: Print Screen or Win+Shift+S
   • Mac: Cmd+Shift+4
   • Linux: Screenshot tool
4. Save as PNG (preferred) or JPEG
5. Optional: Edit/crop/annotate
6. Upload via manage_guide_screenshots.php

═══════════════════════════════════════════════════════════════════════

✅ UPLOAD REQUIREMENTS:

✓ Format: PNG, JPEG, GIF, WebP
✓ Size: < 5MB
✓ Resolution: 1024x768 or higher
✓ Access: ADMIN ONLY
✓ Organization: By section & step number

🎯 ADMIN WORKFLOW:

1. Login as ADMIN user
2. Go to manage_guide_screenshots.php
3. Fill form:
   - Section: vacations / loans / excuse / resignation / rejoin
   - Step: 1 / 2 / 3
   - Title: "Profile Page" (appears below image)
   - Image: Choose PNG/JPEG file
4. Click Upload
5. Screenshots appear in system_guide.php automatically!

🔍 TROUBLESHOOTING:

Problem                     Solution

                          • Check format (PNG/JPEG)
                          • Fill all fields

                          • Check file permissions
                          • Verify database has records

Can't access upload        • Login as ADMIN
                          • Check user_type in DB
