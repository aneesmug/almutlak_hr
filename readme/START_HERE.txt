## 💡 Tips

### Taking Screenshots:
1. Open fresh browser window
2. Log in with test account
3. Navigate to each step
4. Take clean screenshots (hide taskbar, notifications)
5. Highlight important buttons/fields with arrows if needed
6. Hide sensitive data (names, IDs, emails, passwords)

### Uploading Screenshots:
1. Keep them organized (do all Step 1s, then Step 2s, etc.)
2. Use clear, descriptive titles
3. Upload in sequence for easier tracking
4. Verify each upload in the guide
5. Compress large files before uploading

### Quality Checklist:
- [ ] Images are clear and readable
- [ ] Text is not blurry
- [ ] Sensitive data is hidden
- [ ] Resolution is consistent
- [ ] File size is under 2MB
- [ ] Format is JPG, PNG, GIF, or WebP

## 🆘 Need Help?

### Can't Access?
- Make sure you're logged in as admin
- Check user type is "administrator"
- Clear browser cache and try again

### Upload Issues?
- Check file format (JPG, PNG, GIF, WebP only)
- Verify file size is under 5MB
- Try a different image format
- Compress large files

### Display Issues?
- Clear browser cache (Ctrl+F5)
- Try different browser
- Verify file was uploaded successfully
- Check file path in database

### Questions?
- Read: `SCREENSHOT_SYSTEM_COMPLETE_GUIDE.md`
- Check: `SCREENSHOT_UPLOAD_INSTRUCTIONS.md`
- View: `screenshot_requirements.php`

## 🎓 Database Info

### Table: `guide_screenshots`
```sql
Fields:
- id (Primary Key)
- section (vacations, loans, excuse, resignation, rejoin)
- step_number (1-7)
- title (screenshot description)
- filename (original filename)
- file_path (relative path)
- display_order (order within step)
- is_active (show/hide)
- uploaded_by (admin ID)
- created_at (timestamp)
- updated_at (timestamp)
```
